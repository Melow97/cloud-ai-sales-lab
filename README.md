# ATLAS — Cloud & AI Sales Studio

**[Open the live interactive portfolio](https://Melow97.github.io/cloud-ai-sales-lab/)** *(GitHub Pages must be enabled in repository settings before this URL works.)*

ATLAS is an independent, interactive solution-selling case study created by **Mel Ozturk**. It demonstrates how a B2B Cloud & AI sales specialist might move from customer discovery to use-case mapping, stakeholder qualification, financial value framing and a pilot decision.

## Portfolio highlights

- **Consultative discovery:** three fictional mid-market customer scenarios and guided discovery questions.
- **Business-value modelling:** adjustable headcount, time savings, loaded labour cost and total solution cost assumptions.
- **AI solution positioning:** conceptual capability mapping to Microsoft cloud and AI product families without claiming a certified solution.
- **Commercial workflow:** discover → qualify → validate → propose → adopt.
- **Executive deliverable:** downloadable opportunity brief and print-friendly view.
- **Accessible:** mobile-friendly, no login, no API key, no backend.

## How to run
Open `index.html` locally in a modern browser, or enable GitHub Pages from the `main` branch / repository root.

## Financial-model formula
- Gross monthly labour value = employees × assumed monthly hours saved × fully loaded hourly cost.
- Net monthly value estimate = gross monthly labour value − assumed total monthly solution cost.
- Illustrative ROI = (gross annual benefit − annual assumed cost) / annual assumed cost × 100.

Time saved is **not automatically money saved**. Implementation, governance, licensing, integration, adoption and risk must be assessed before a genuine business case.

## Customer conversations
1. What workflows have measurable friction and what is the baseline?
2. Who controls budget, data access and adoption?
3. Which stakeholders and security requirements affect the pilot?
4. What evidence would justify a rollout?
