# ATLAS — Cloud & AI Sales Studio

**[Open the live interactive portfolio](https://Melow97.github.io/cloud-ai-sales-lab/)** *(GitHub Pages must be enabled in repository settings before this URL works.)*

ATLAS is an independent, interactive solution-selling case study created by **Mel Ozturk**. It demonstrates how a B2B Cloud & AI sales specialist might move from customer discovery to use-case mapping, stakeholder qualification, financial value framing and a pilot decision.

## New: Cloud Solution Architect Lab (IC2)

[**Open the interactive architecture workshop**](./architect-lab.html) — a fictional customer exercise covering Azure-oriented architecture decisions, Entra identity, data governance, integration constraints, pilot-readiness checks, financial assumptions (including one-time implementation cost), and downloadable workshop briefs. This is conceptual design, **not a deployed Azure environment** or proof of professional cloud experience.

Suggested interview flow: choose the retail scenario → change the data sensitivity and integration options → explain architecture trade-offs and risks → discuss pilot KPIs → export a workshop brief.

## Architecture decision review

[Open the five-pillar self-assessment](./architecture-review.html). A guided educational review of reliability, security, cost optimization, operational excellence, and performance efficiency, with 15 explainable considerations, automatically generated gap priorities, and a downloadable Markdown decision memo. Checked items represent unverified design intentions, not deployed or audited controls.

**Recruiter demo (5 minutes):** start with the customer scenario in the Architect Lab, explain a security/integration trade-off, open the architecture decision review, check a few decisions, export the remaining action plan, and describe what real Azure deployment evidence would be needed next.

**Evidence levels:** (1) simulated design: these browser labs; (2) local prototype: requires tests and artifacts; (3) deployed cloud POC: requires a verified Azure endpoint, resources, logs, cost information and security review; (4) production engagement: not claimed. Do not present simulations as professional Azure experience.

## New: cloud architect customer decision simulator

[**Launch the interactive interview simulator**](./interview-simulator.html). Six customer scenarios cover discovery, Entra-aware permissions, AI output quality, repeatable deployment and monitoring, ROI/TCO, and adoption. Each scenario has educational scoring, feedback on trade-offs and a downloadable Markdown review.

**Five-minute recruiter walkthrough:** Start with a fictional support customer → explain discovery and data boundaries → compare a good security choice against a tempting shortcut → discuss infrastructure-as-code and monitoring → export the review. This is an independent **learning exercise, not a Microsoft-approved assessment or evidence of a deployed Azure environment**.

## Copilot-inspired AI Advisor (scripted demo)

[Open the AI Advisor](./ai-advisor.html) to demonstrate a fictional customer advisory conversation, intent matching, follow-up discovery, security considerations, Copilot Studio versus Microsoft Foundry positioning, and export of a brief. **This is a deterministic JavaScript rules engine, not Microsoft Copilot, an LLM, a Copilot Studio deployment, or an Azure AI integration.** It requires no API key and makes no network calls. It is a transparent prototype of the user experience and intended workflow.

A real AI integration would need approved platform access, authenticated backend or Copilot Studio publishing, permission-aware knowledge, evaluation, telemetry, licensing, and cost and privacy reviews. Never expose provider secrets or proprietary customer information in a public static website.

## Financial-model formula
- Gross monthly labour value = employees × assumed monthly hours saved × fully loaded hourly cost.
- Net monthly value estimate = gross monthly labour value − assumed total monthly solution cost.
- Illustrative ROI = (gross annual benefit − annual assumed cost) / annual assumed cost × 100.

Time saved is **not automatically money saved**. Implementation, governance, licensing, integration, adoption and risk must be assessed before a genuine business case.
